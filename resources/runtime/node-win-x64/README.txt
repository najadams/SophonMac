Node.js Runtime for Windows x64
================================

This directory contains the Node.js v20.19.3 binary for Windows x64 architecture.

The node.exe file in this directory will be bundled with the Sophon application
and used to run the backend server when the application is packaged for distribution.

This ensures the application can run standalone without requiring Node.js to be
installed on the target Windows machine.

File: node.exe (Node.js v20.19.3 for Windows x64)
